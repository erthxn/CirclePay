# CirclePay

Reward your X circle with crypto via PayBox.

Analyze recent high-quality interactions (quotes, mentions) over the last 7 days, rank contributors by engagement score, and generate a weighted payment prompt for AI agents (Claude, Grok, ChatGPT + PayBox).

## Stack
- Next.js (App Router)
- Vercel
- Pure SVG branding

Domain target: circlepay.fun
